# doc/ · 历史归档（不作为工作文件参考）

> **本目录不作为工作文件参考。**
> 这里存放的是通用 agent 重构过程中从工程根目录剥离下来的**专用领域设计**与**接口 / 接入设计**文档，
> 以及同期的历史计划与路线图。保留仅为存史与查证，**不参与当前开发**，也不随代码演进。

## 归档原因

- **agent 已通用化**：领域内容（选品策略、评分管线）与引擎接入设计都不再属于 agent 本体。
- **文档没有可执行的对应物**：相关代码已从 `agent/` 移除（各项「状态」栏注明），这些文档指向的表、模块、入口多已不存在。
- **避免误导**：留在根目录容易被当作现行依据，故整体移入 `doc/` 并加此说明。
