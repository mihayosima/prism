## 一、目标

让后端**单端口托管**前端构建产物 `web/dist/`，从而删除 `agent/run/chat.py` 里
55,314 字符的 `_PAGE` 常量（1679 行 → 约 1080 行，**瘦身 ~35%**），
完成「前后端完全分离」。

## 二、现状诊断（已实测）

| 项 | 实测 |
|---|---|
| `_PAGE` 体积 | **55,314 字符**（内联 HTML + CSS + JS 的 legacy 版） |
| `chat.py` 总行数 | 1679 |
| 前端产物 | `web/dist/index.html` + `assets/index-*.js`(108KB) + `index-*.css`(9.8KB) |
| 产物引用方式 | **绝对路径** `/assets/index-*.js` ← 正是单端口托管所需 |
| 前端路由 | **状态切换**（非 history）⇒ 无需 SPA 回退 |
| 后端路由 | 20 个 `/api/*` + `GET /` |

### ★ 关键发现：7 处后端契约测试直接断言 `srv._PAGE`

| 文件 | 断言 | 意图 |
|---|---|---|
| `test_budget_reset.py:64` | `"'max_tokens_per_run'" in srv._PAGE` | 设置键须同步到前端 |
| `test_context_governor.py:616` | `f"'{k}'" in srv._PAGE` | 同上（多键循环） |
| `test_followup_topics.py:355` | `f"set_{k}" in srv._PAGE` | 前端 id 须同步 |
| `test_incident_fixes.py:375` | `"'finalize_reserve_tokens'" in srv._PAGE` | 同上 |
| `test_p1_contract_waterline.py:216` | `srv._PAGE.count(f"'{k}'") >= 2` | **须出现两次**（字段表 + 保存列表） |
| `test_p2_governance_verbs.py:325` | `key in srv._PAGE` | 同上 |

**本质**：这 7 处是**前后端契约守卫** —— 后端加了设置键，前端必须跟上。
**删 `_PAGE` 后若不迁移，这层保护会静默消失**（最忌讳的"为变绿删断言"）。

**已确认前端有完整等价物**（`web/src/views/settings.logic.ts`）：
- `SETTINGS_NUMERIC_KEYS` 数组（含 `max_tokens_per_run`、`finalize_reserve_tokens`…）
- `CONTEXT_FIELDS` 数组（含 `clear_at_least_tokens`…）
- `set_<k>` 形式的 input id（`set_max_tokens_per_run`）
- 键名字面量确实出现 ≥2 次

⇒ **可等价迁移**，契约保护不丢失。

## 三、技术可行性（已只读实测）

以最小 ASGI app 验证 `StaticFiles(html=True)` 挂在 `/` 的语义：

```
/                    -> 200  index.html
/assets/a.js         -> 200  console.log(1)
/api/status          -> 200  {"ok":true}      ← /api/* 正常优先，不冲突
/nonexistent         -> 404
```

结论：**`api` 路由先注册、`StaticFiles` 最后挂载 `/`** 即可共存，
`/` 返回 index.html、`/assets/*` 命中真实文件。

## 四、改动清单（**后端仅动 `chat.py`**，内核/插件零改动）

### B4.1 `_serve` 内新增托管（约 20 行）

```python
# 在全部 @app.get/@app.post 路由**之后**（关键：StaticFiles 必须最后注册）
_DIST = Path(__file__).resolve().parents[2] / "web" / "dist"
if _DIST.is_dir():
    from fastapi.staticfiles import StaticFiles
    app.mount("/", StaticFiles(directory=str(_DIST), html=True), name="web")
    # GET / 交给 StaticFiles(html=True) 处理 → 返回 dist/index.html
else:
    # 未构建：明确报错，而不是静默 404（避免"页面打不开但不知道为啥"）
    @app.get("/")
    async def _home_missing():
        return HTMLResponse(
            "<h1>前端产物缺失</h1><p>请先执行：cd web && npm install && npm run build</p>",
            status_code=503)
```

- 删除 `_PAGE` 常量（271–约 1250 行区段）。
- 同步删掉原 `_home()` 里对 `_PAGE` 的引用。
- `--dev-dist` 之类开关**不需要**：产物存在就托管，不存在给明确提示。

### B4.2 迁移 7 处契约测试（**新增** `agent/tests/_web_sources.py` 辅助）

不删断言，只换数据源：把「读 `srv._PAGE`」改为「读前端源码文本」。

```python
# agent/tests/_web_sources.py（新增，约 20 行）
"""前后端契约守卫：后端设置键必须同步到前端源码。

B4 前，守卫读 chat.py 内联的 _PAGE；B4 后前端独立成 web/ 工程，
故改为读前端源码（settings.logic.ts）—— **保护强度不变，只是换了数据源**。
"""
from pathlib import Path

_WEB = Path(__file__).resolve().parents[2] / "web" / "src"

def frontend_settings_source() -> str:
    """返回承载设置键的前端源码文本（settings.logic.ts）。"""
    return (_WEB / "views" / "settings.logic.ts").read_text(encoding="utf-8")
```

测试改法（7 处一一对应）：
```python
# 旧
assert "'max_tokens_per_run'" in srv._PAGE
# 新
assert "'max_tokens_per_run'" in frontend_settings_source()
```
